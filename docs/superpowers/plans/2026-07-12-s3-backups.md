# S3 Backups Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ejecutar respaldos diarios cifrados de Postgres y Supabase Storage desde AWS Fargate hacia un bucket S3 privado e inmutable.

**Architecture:** Un contenedor ejecuta `pg_dump`, sincroniza cada bucket S3-compatible de Supabase y crea un manifiesto SHA-256. Terraform define S3, KMS, Secrets Manager, IAM, ECS Fargate, EventBridge y alertas; el contenedor recibe secretos solo en ejecucion.

**Tech Stack:** Bash, Docker, PostgreSQL client, rclone, age, AWS CLI, Terraform, AWS ECS Fargate, EventBridge, S3, KMS, Secrets Manager y CloudWatch.

- [ ] **Step 3: Implementar el generador minimo de manifiesto**

```bash
write_manifest() {
  local target="$1" backup_date="$2" source_dir="$3"
  {
    printf '{"backup_date":"%s","artifacts":[' "$backup_date"
    find "$source_dir" -type f -print0 | sort -z | while IFS= read -r -d '' file; do
      printf '{"name":"%s","sha256":"%s"},' "$(basename "$file")" "$(shasum -a 256 "$file" | awk '{print $1}')"
    done | sed 's/,$//'
    printf ']}\n'
  } > "$target"
}
```

- [ ] **Step 3: Implementar validacion, dump y cifrado**

```bash
require_secret() { test -n "${!1:-}" || { echo "Falta $1" >&2; exit 64; }; }
for secret in SUPABASE_DB_URL SUPABASE_S3_ENDPOINT SUPABASE_S3_ACCESS_KEY_ID SUPABASE_S3_SECRET_ACCESS_KEY BACKUP_AGE_PUBLIC_KEY; do require_secret "$secret"; done

backup_root="/tmp/backup/$(date -u +%F)"
mkdir -p "$backup_root/storage"
pg_dump --format=custom --no-owner --no-privileges --file "$backup_root/database.dump" "$SUPABASE_DB_URL"
age -r "$BACKUP_AGE_PUBLIC_KEY" -o "$backup_root/database.dump.age" "$backup_root/database.dump"
rm -f "$backup_root/database.dump"
```

- [ ] **Step 4: Sincronizar buckets y cifrar cada archivo antes de subirlo**

```bash
for bucket in ${SUPABASE_STORAGE_BUCKETS:?}; do
  rclone sync "supabase:${bucket}" "$backup_root/storage/${bucket}" --fast-list
  tar -C "$backup_root/storage" -cf - "$bucket" | age -r "$BACKUP_AGE_PUBLIC_KEY" -o "$backup_root/${bucket}.tar.age"
  rm -rf "$backup_root/storage/${bucket}"
done
write_manifest "$backup_root/manifest.json" "$(date -u +%F)" "$backup_root"
aws s3 cp "$backup_root" "s3://${BACKUP_BUCKET}/daily/$(date -u +%F)/" --recursive --sse aws:kms
```
